过滤规则

规则之间是「任一命中即过滤」。所有规则的优先级都低于白名单。数值型规则的阈值单位见下拉框右侧。

启用 指标 条件 阈值 / 关键词 备注

还没有任何规则。点右上角「添加规则」，或去「预设规则包」一键导入一套。

提示：互动率（点赞率/投币率等）在播放量低于「高级 → 互动率最小样本」时视为不可信，不参与判定， 避免把刚发布的小播放量视频误判成低质。

批量关键词

一行一个词，也可以用逗号、顿号、分号分隔。粘贴一大段进去会自动切分去重。不区分大小写。

标题关键词

标题里出现任意一个词 → 过滤

0 个词

UP主名关键词

UP 主昵称里出现任意一个词 → 过滤

0 个词

标签关键词 需额外请求

视频标签里出现任意一个词 → 过滤（每条视频一次请求，有缓存）

0 个词
这三组词分别对应规则表里的一条「包含任意」规则。在规则表里也能改，两边是同一份数据。

白名单 / 黑名单

白名单优先级最高：命中的视频永远不会被过滤。黑名单 UP 优先级仅次于白名单，一键屏蔽就存在这里。

白名单 · UP 主 mid

一行一个数字 mid，最精确

白名单 · UP 主名

一行一个名字片段

白名单 · 标题词

标题含这些词就放行

白名单 · 标签词

标签含这些词就放行

黑名单 · 已屏蔽的 UP

在播放页卡片上点「屏蔽此UP」会加到这两个列表。mid 一行一个，名字一行一个。

预设规则包

点「导入」会把预设展开成普通规则追加进规则表，之后可以随意改、随意删。重复的规则不会重复导入。

高级

这些开关影响性能与风控风险，不确定就保持默认。

关闭后「标签关键词」和「UP主投稿频率」规则完全不生效，只用接口自带字段判定，零额外请求。

一个播放页右侧约 40 条推荐，标签需要逐条请求，UP 频率按 UP 去重。调低可以显著降低风控风险，代价是部分卡片判定为「未知」而放行。

播放量低于此值时，点赞率/投币率等视为不可信，不参与判定。

鼠标移到卡片上出现「屏蔽此UP」「标题词+」。

导出会把规则、批量关键词、白名单、黑名单和高级设置一起存成一个 JSON 文件，方便备份或换电脑时迁移。 导入会覆盖当前全部配置，导入前会再确认一次。
